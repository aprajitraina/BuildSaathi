# modules/billing/

Billing & Invoice Tracker — manage invoices and payment tracking.

## Status: Phase 2

This module is scaffolded but not yet implemented.

## Planned Responsibilities

- Create and manage invoices against projects
- Track payment status (draft → sent → partially paid → paid)
- Overdue invoice alerts
- Payment history per project
- GST invoice generation (Phase 3)

## Key Flow

Project Completion → Create Invoice → Send to Client → Track Payment → Mark Paid
