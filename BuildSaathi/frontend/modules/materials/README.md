# modules/materials/

Material Price Tracker — monitor construction material rates and supplier comparisons.

## Status: Phase 2

This module is scaffolded but not yet implemented.

## Planned Responsibilities

- View current market rates for materials (cement, steel, sand, bricks, etc.)
- Historical rate trend charts
- Supplier comparison table
- Rate alerts when prices move significantly

## Data Source

Material rates are seeded and periodically updated from public market sources.
Suppliers can eventually submit rates via the procurement marketplace (Phase 3).
